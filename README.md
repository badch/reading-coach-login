# 智慧朗讀教練 (Reading Coach) 📖🎙️

一個為繁體中文/國語朗讀練習打造的現代化 Web 應用程式。使用者可以拍照上傳課文或文章，由 AI 辨識文字、提供標準示範朗讀，並在使用者錄音跟讀後，即時診斷並計算朗讀正確率！

---

## ✨ 核心特色與功能

1. **拍照辨識文章 (OCR) & 雲端全班同步範例庫**
   - 支援手機相機拍照、相簿選圖或電腦檔案拖放，採用 **Tesseract.js** 繁體中文辨識。
   - **雲端班級代碼同步（老師發布，全班秒同步）**：老師設定班級代碼（如 301），一鍵發布範例；學生平板輸入代碼或掃描 QR Code 自動同步所有文章！
   - **直達 QR Code / 連結分享**：自動生成帶有班級參數的直達連結與 QR Code，投影在黑板上學生平板一掃即開啟！
   - **本機永久儲存與備份**：支援離線快取與 JSON 匯入/匯出。
   - 內建精選範例文本（唐詩《春曉》、《雅量》節錄、《背影》片段）。

2. **朗讀專用讀稿窗（Teleprompter）與錄音防中斷守護**
   - **眼前直接看文章**：錄音按鈕正上方內建大字體讀稿窗，朗讀時眼睛平視即可朗讀，**徹底免去上下滑動螢幕**！
   - **字體自由縮放（A- / 標準 / A+）與直排模式切換**：特別適合國小課文與古詩詞的朗讀習慣。
   - **滑動手勢音訊守護（AudioContext KeepAlive）**：杜絕行動端滑動手勢與拉伸造成的音訊中斷。

3. **示範朗讀（語音合成 TTS）**
   - 採用瀏覽器原生 **Web Speech Synthesis API**，零延遲、免額外付費與免設定 API Key。
   - 自動適配繁體中文（台灣 `zh-TW`）語音。
   - 支援 **語速切換**（慢速 0.75x、正常 1.0x、快速 1.25x），方便依程度學習節奏。

4. **硬體層真實錄音與即時辨識 (MediaRecorder + STT)**
   - 採用 HTML5 **MediaRecorder** 本地真實錄音，支援跳動頻譜可視化與錄音回放。
   - 與 Web Speech 語音識別雙軌並行，自動過濾標點符號，精準比對。

4. **精準正確率比對與視覺化報告**
   - **LCS (最長公共子序列) 演算法**：精準對齊標準原文與使用者朗讀語音。
   - **四大核心數據指標**：
     - 總體正確率百分比（0% ~ 100%）
     - 唸讀正確字數（綠色標記 ✅）
     - 漏讀 / 誤差字數（紅色刪除線標記 ❌）
     - 多讀 / 贅字數（黃色標記 ⚠️）
   - **智慧教練評語**：依表現給予五星等級評分與量身打造的改進建議。
   - **高分慶祝動畫**：達 90% 以上即發射全螢幕彩帶禮炮！🎉

5. **學生登入與 Firebase 雲端成績歷程檔案**
   - **課堂免密碼快速登入**：學生輸入「班級、座號、姓名」（如 301 班 05 號 王小明），免記複雜密碼，開箱即用；亦支援 Google 帳號一鍵登入。
   - **每次朗讀即時自動存檔**：朗讀診斷完成後，系統自動將「課文標題、正確率、星等、正/漏/贅字數、耗時」寫入 **Google Cloud Firestore**（離線或未連線時自動無縫存入本地 LocalStorage）。
   - **個人朗讀成績單與成長曲線**：隨時點擊「朗讀成績單」查看累積練習次數、平均正確率、最佳分數與歷次詳細紀錄。
   - **老師全班成績榜與一鍵匯出 CSV**：老師可隨時切換查看全班所有學生表現，並一鍵匯出 Excel/CSV 表格進行期末打分數。
   - **前端免改扣設定視窗**：點擊右上角設定圖示，可直接在介面貼上 Firebase 專案配置即刻啟用雲端。

## 🚀 快速啟動方式

因為現代瀏覽器的麥克風權限與 Web Worker 安全性限制，建議透過 `http://localhost` 本地伺服器開啟以獲得完整功能：

### 方法一：使用 Python 內建伺服器（推薦，自動開網頁）

在終端機中執行：
```bash
cd "/Users/chungchu/一般使用AI/reading-coach"
python3 server.py
```
> 執行後將自動開啟瀏覽器至 `http://localhost:8080`。

## 🌐 發布到公開網站（讓大家用平板/手機連線朗讀）

因為行動裝置（iPad / Android 平板）要求 **HTTPS 安全網址** 才能允許使用相機與麥克風，本專案為純靜態網頁（無任何後端依賴），您可以透過以下最簡單的方法免費發布：

### 推薦方法一：Netlify Drop（最快速！免指令、30 秒產生專屬網址）
1. 打開瀏覽器訪問：[https://app.netlify.com/drop](https://app.netlify.com/drop)
2. 將電腦中的 `reading-coach` 資料夾整包**拖曳**到該網頁的拖曳區域中。
3. 系統會立刻為您產生一組免費的 HTTPS 專屬網址（例如 `https://reading-coach-xxxx.netlify.app`）。
4. 將網址或產生的 QR Code 提供給學生/使用者，即可直接在平板上掃描開啟！

### 推薦方法二：GitHub Pages
1. 在 GitHub 建立一個公開倉庫（如 `reading-coach`）。
2. 將本資料夾檔案推送至該倉庫：
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin <您的 GitHub 倉庫網址>
   git push -u origin main
   ```
3. 前往 GitHub 倉庫的 **Settings** -> **Pages**，將 Branch 選為 `main` 並儲存。
4. 幾分鐘後即可在 `https://<您的帳號>.github.io/reading-coach/` 永久訪問！

## 💡 使用流程

1. **步驟 1：取得文章**
   - 點擊「選取檔案」或在手機上點選相機拍照。
   - 也可以點選「唐詩《春曉》」等範例按鈕快速載入。
2. **步驟 2：聽示範朗讀**
   - 點擊「播放示範朗讀」，聆聽發音與停頓節奏。
3. **步驟 3：開始跟讀錄音**
   - 點擊紅色圓形「開始朗讀」按鈕。
   - 允許瀏覽器麥克風權限，大聲朗讀課文。
   - 唸完後再次點擊按鈕結束。
4. **步驟 4：查看評分報告**
   - 系統自動產生正確率、星級評等、字詞比對與教練建議！
